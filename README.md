# Means+Measures · GitHub Community Infrastructure

**Equity of means. Equality of measures.**

This repository maintains the shared GitHub infrastructure, contribution standards, and community documentation for [Means+Measures](https://github.com/MeansAndMeasures).

Means+Measures builds infrastructure, data systems, and tools that make complex institutions easier to navigate. Our work begins with a question: **Who is most likely to be excluded, and what would it take to build the system so they aren't?**

## Repository purpose

The `.github` repository provides a central location for:

- **Organizational identity:** Our public GitHub profile and foundational principles.
- **Participation:** Contribution guidance, issue templates, and collaboration practices.
- **Accountability:** Governance documentation and consistent standards for evaluating contributions.
- **Security:** Vulnerability disclosure guidance and responsible reporting.
- **Shared infrastructure:** Supported configuration and automation defaults across participating repositories.

## Guiding principles

**Equity of means:** Lack of privilege is not lack of access.

**Equality of measures:** Impacts are judged on their own merits, not the standing of the institution.

Institutions bear responsibility **down through systems** for making the means of participation accessible.

Authority rises **up through people** who question, evaluate, and hold those institutions accountable.

These principles inform how we design, document, maintain, and evaluate our work.
