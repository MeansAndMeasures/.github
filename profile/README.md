# Means+Measures
 
**Down through systems. Up through people.**
 
Means+Measures is a small Missouri company that builds infrastructure, data, and analysis tools. We start every project with one question: who is most likely to be shut out of this, and what would it take to build it so they aren't? We answer that before anything else is designed, not as a fix added at the end.
 
## Why we exist
 
A lot of public systems, like benefits, services, records, and the data behind them, are hard to get through unless you have a professional working on your behalf. We build tools for the person the system is actually about, so they can get through it themselves.
 
That shapes everything we build:
 
- **Access:** If a system is supposed to serve people, people should be able to use it directly.
- **Shared knowledge:** We document what we learn and publish it openly, so technical know-how spreads instead of staying with a few experts.
- **Accountable AI:** Where we use AI, it should serve the person using it, and it should be possible to see what it did and why.
- **Keeping public resources publicL** Open data and community knowledge should stay open, not get absorbed into products that a few large companies control.

## What we build
 
**[CivicNavigator](https://meansandmeasures.com/civicnavigator)** *(in development)*
Civic navigation and mutual aid for people who receive official paperwork: housing notices, benefits letters, insurance forms, court papers, school and government documents. It explains the paperwork in plain language, keeps your documents, questions, and next steps in one record, and connects your situation to local resources and people who can help. Resource connections start with the Kansas City metro.
 
**[Kansas City services directory — English](https://meansandmeasures.com/kc/directory) · [Español](https://meansandmeasures.com/es/kc/newcomers)**
A free, bilingual (English/Spanish) directory of food, housing, healthcare, legal aid, veterans' services, utilities, transit, and more across the nine-county Kansas City metro in both Kansas and Missouri. It's independent and has no ads. The full dataset can be downloaded as JSON or CSV, and anyone may copy and redistribute it.
 
**[Forecast](https://meansandmeasures.com/work/forecast)** ([live](https://forecast.meansandmeasures.com))
Real-time situational awareness. It pulls together live data that normally sits in separate places, including aviation reports, National Weather Service data, lightning, wildfire smoke, active fires, air quality, traffic, and news, so you can see conditions in one view. Every incoming record is checked against a defined format before it's used.
 
**[Open Cognition](https://meansandmeasures.com/work/open-cognition)**
A shared memory system for AI agents, which are programs that carry out tasks on someone's behalf. When several agents share what they know, you need to be able to tell who recorded each piece of information, under what authority, and whether it can still be trusted. Open Cognition keeps that record. Licensed MPL-2.0.
 
**[PSIF — Package Search and Install Federator](https://meansandmeasures.com/work/psif)**
One Windows command for finding and installing software across nine package ecosystems, so you don't have to learn each one separately.

Our public repositories accept issues and pull requests.
 
You don't need to write code to help. For a directory or dataset, fixing a wrong phone number, outdated hours, or an incorrect eligibility rule can matter more than a code change, because people rely on that information to get help. Report those problems the same way you'd report a bug.
